# 📊 Proyecto de Normalización de Base de Datos y Despliegue Web

Proyecto académico enfocado en el diseño relacional avanzado de bases de datos, estructurado desde la **Primera hasta la Quinta Forma Normal (1FN - 5FN)** utilizando Oracle SQL Developer, migrado a un entorno cloud con **Supabase (PostgreSQL)** y visualizado en la web mediante **GitHub Pages**.

---

## 🛠️ Stack Tecnológico y Arquitectura

* **Diseño y Modelado Local:** Oracle SQL Developer / Oracle Database (1FN - 5FN).
* **Backend y Base de Datos en la Nube:** Supabase (PostgreSQL + Vistas SQL + API).
* **Frontend y Despliegue:** HTML5, CSS3, JavaScript (`@supabase/supabase-js`) y GitHub Pages.

---

## 📈 Formas Normales Implementadas

1. **1FN (Primera Forma Normal):** Eliminación de grupos repetitivos asegurando que todos los atributos contengan valores atómicos.
2. **2FN (Segunda Forma Normal):** Cumplimiento de la 1FN y eliminación de dependencias parciales (claves compuestas totalmente funcionales en tablas de detalle).
3. **3FN (Tercera Forma Normal):** Eliminación de dependencias transitivas (separación estricta de entidades como `clientes` y `productos`).
4. **4FN y 5FN (Cuarta y Quinta Forma Normal):** Descomposición de dependencias multivaluadas y relaciones complejas (ej. asignación independiente de proveedores y proyecciones de unión).
